# Giới thiệu game

**The Last Bite** là game sinh tồn góc nhìn từ trên xuống (**Top-down Survival**), đồ họa **2D Pixel Art**. Người chơi sẽ hóa thân thành người sống sót cuối cùng trong thế giới hậu tận thế, nơi bầy xác sống tràn ngập khắp nơi và một con quái vật biến dị đang ẩn nấp dưới ga tàu điện ngầm.

---

# Cốt truyện

Ngày tận thế đến. Thế giới chỉ còn lại bạn.
Lũ thây ma tràn ngập khắp mọi nẻo đường. Nhưng mối nguy hiểm thực sự vẫn đang nấp sâu dưới lòng đất – tại nhà ga tàu điện ngầm trung tâm.

Một con quái vật biến dị với những xúc tu khổng lồ và bào tử độc chết người đang lớn dần lên từng ngày.

Hãy tìm chìa khóa, đột nhập vào hang ổ của nó, và kết liễu con quái vật – trước khi nó kết liễu bạn.

> Bởi đây là **The Last Bite** – cơ hội cuối cùng của nhân loại.

---

# Mục tiêu

* Thu thập vũ khí, lương thực và vật phẩm y tế
* Sống sót qua chu kỳ ngày/đêm

  * Ban ngày: 20 phút
  * Ban đêm: 10 phút
* Tìm **Chìa khóa gốc** được giấu ngẫu nhiên trong thành phố
* Đột nhập vào hầm tàu điện ngầm và tiêu diệt Boss

# Tính năng chính

## Gameplay

* Di chuyển 8 hướng mượt mà với hệ thống thể lực (**Stamina**)
* Hệ thống ngày/đêm – Zombie mạnh hơn khi trời tối
* Enemy AI thông minh – Zombie đuổi theo và tránh chướng ngại vật
* Chiến đấu với Boss – Quái vật biến dị với 2 dạng tấn công:

  * Đạn độc
  * Xúc tu

## Hệ thống Inventory

* Túi đồ 10 ô – nhặt, sử dụng, vứt bỏ, kéo thả item
* Hotbar 5 ô – chọn nhanh bằng phím số `1-5`
* Stack item – tối đa `99` vật phẩm cùng loại

## Thế giới mở

* Bản đồ `100x100` ô với nhiều tòa nhà có thể đột nhập
* Cơ chế trú ẩn – vào nhà để tránh Zombie và hồi stamina nhanh
* Sinh ngẫu nhiên – chìa khóa và vật phẩm thay đổi mỗi lần chơi

## Đồ họa & Âm thanh

* Pixel Art 2D phong cách retro
* Hiệu ứng ánh sáng – Global Light 2D thay đổi theo thời gian
* Nhạc nền và SFX có thể điều chỉnh âm lượng

## Cách tải và chạy game

### Cách 1: Tải bản build (Không cần Unity)

Tải game tại:

```txt
https://drive.google.com/drive/folders/1O7aVUH-h4j_mj3I8awMgGIjz6WxPchrm?usp=drive_link
```

Sau đó chạy file:

```txt
The Last Bite.exe
```

---

### Cách 2: Chạy từ source code (Unity)

### Yêu cầu

* Unity Hub
* Unity `6000.3.7f1` hoặc mới hơn

### Clone repository

```bash
git clone https://github.com/your-team/TheLastBite.git
cd TheLastBite
```

### Mở project

1. Mở Unity Hub
2. Chọn **Add Project**
3. Chọn thư mục project

### Chạy game

* Mở scene:

```txt
Assets/Scenes/MainMenu.unity
```

* Nhấn **Play** để chạy trong Unity Editor

### Build game

```txt
File → Build Settings → Build
```
